# 🚀 Codomax Full-Stack Blog Application

A secure full-stack blogging platform built with **Node.js, Express.js, MongoDB, and JWT Authentication**. Developed as part of the Codomax Digital Solutions Internship.

## 🛠️ Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** MongoDB & Mongoose
- **Authentication:** JSON Web Tokens (JWT), Bcrypt.js
- **Version Control:** Git & GitHub

## ✨ Features
- **User Authentication:** Secure user registration and login with hashed passwords and JWT.
- **Full CRUD Operations:** Create, Read, Update, and Delete blog posts.
- **Search & Filtering:** Filter blog posts by keywords or categories.
- **Protected Dashboards:** Users can view, update, and delete only their own blog posts.
